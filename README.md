# Control automático de llenado de tanque

Estudio de caso educativo desarrollado en Factory I/O y Control I/O mediante lógica FBD.

## ¿Qué hace?

La simulación controla el llenado automático de un tanque y muestra su nivel en un display. Utiliza indicadores de nivel bajo, medio y alto; detiene el llenado al alcanzar el nivel máximo y permite simular una fuga y una avería en la válvula con alarmas visuales.

## Herramientas y lógica

- Factory I/O y Control I/O
- Diagramas de bloques funcionales (FBD)
- Lectura analógica de nivel
- Comparadores, temporizadores, compuertas lógicas y memorias RS

## Validación

El funcionamiento se documentó mediante 12 pruebas funcionales. Este es un proyecto personal con fines educativos, no una solución certificada para uso industrial.
